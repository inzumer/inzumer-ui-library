# Chevron

A decorative chevron drawn with `currentColor`, pointing `down` (default), `up`, `left` or
`right`. Used by `Select`, `Dropdown`, `Accordion` and `Carousel`; size and color come from
`className`. It is `aria-hidden`: name the control it sits in, not the icon.

```tsx
import { Chevron } from '@inzumer/ui-library';

<Chevron direction="right" className="size-5" />;
```
