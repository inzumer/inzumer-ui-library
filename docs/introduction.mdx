# Inzumer UI Library

`@inzumer/ui-library` is the shared React component library for the Inzumer design system. It provides
accessible, token-driven components (`Button`, `Input`, `Card`) meant to be installed into other
repositories — currently the two reference consumers are the **inzumer** and **zamuner** sites — instead
of copy-pasting UI code between projects.

## Why this exists

- **One source of truth for UI.** A button fix or a new input state ships once, from this repo, instead
  of being duplicated (and drifting) across every project that needs it.
- **Token-driven, not hardcoded.** Components never hardcode a hex color or a pixel value — they read
  CSS custom properties (`var(--btn-primary-bg)`, `var(--surface-primary)`, ...) supplied by
  `@inzumer/tokens`. Rebranding a consumer app means swapping the token values, not editing component
  code — see [Overriding Styles](/docs/documentation-overriding-styles--docs).
- **Accessible by default.** Semantic HTML, visible focus states, and keyboard support are
  non‑negotiable — enforced by `eslint-plugin-jsx-a11y` at lint time and `@storybook/addon-a11y`
  (axe-core) at render time.

The tokens and the shared tooling live in their own repositories, one per package
(`inzumer-<name>` → `@inzumer/<name>`): [`inzumer-tokens`](https://github.com/inzumer/inzumer-tokens),
[`inzumer-eslint`](https://github.com/inzumer/inzumer-eslint),
[`inzumer-prettier`](https://github.com/inzumer/inzumer-prettier) and
[`inzumer-tsconfig`](https://github.com/inzumer/inzumer-tsconfig).
