# Installation

## Prerequisites

- Node.js **>=18**
- **pnpm >=9** to work on this monorepo itself (`packageManager: "pnpm@9.15.9"` in the root
  `package.json`). Run `corepack enable` if the `pnpm` command isn't on your PATH.
- Consumers of the published packages can use npm, yarn, or pnpm — the packages themselves don't
  require pnpm.

## Working on this repo

```bash
git clone <this-repo>
cd inzumer-ui-library
pnpm install
```

That installs `packages/ui` and its tooling in one pass. The design tokens
(`@inzumer/tokens`) and the shared configs (`@inzumer/eslint`, `@inzumer/prettier`,
`@inzumer/tsconfig`) come from their own `inzumer-*` repositories. See
[Tech Stack](/docs/documentation-tech-stack--docs) for what each tool does, and run `pnpm storybook`
to open this documentation locally at `http://localhost:6006`.

## Installing the published packages in another project

```bash
pnpm add @inzumer/ui-library @inzumer/tokens
# or: npm install / yarn add
```

`@inzumer/ui-library` declares these as **peer dependencies** — install them too if your project
doesn't already have them:

```bash
pnpm add react react-dom class-variance-authority clsx tailwind-merge
```

Peer dependencies are **not** bundled into `@inzumer/ui-library` — this keeps the package small and
avoids shipping a second copy of React in your app.

## Minimum setup

1. Add the Tailwind preset from `@inzumer/tokens` to your app's `tailwind.config.ts` (see
   [Design Tokens](/docs/documentation-design-tokens--docs)).
2. Import the base tokens CSS somewhere loaded once (e.g. your root layout), so the CSS custom
   properties components rely on (`--btn-primary-bg`, `--surface-primary`, ...) exist:

   ```ts
   import '@inzumer/tokens/css/reset';
   import '@inzumer/tokens/css/variables';
   import '@inzumer/tokens/css/typography';
   ```

   `css/reset` sets `html { font-size: 62.5% }`, i.e. `1rem = 10px` at the browser's default —
   every spacing/radius/font-size token is scaled to match, so components only render at their
   intended size when this reset is applied. If your app sets its own root font-size elsewhere,
   make sure it's also `62.5%` (or don't override it), or components will render at the wrong
   scale. This still respects the user's own font-size preference either way, since it's a
   percentage of their browser/OS default, not a fixed pixel value.

3. Import and use components:

   ```tsx
   import { Button } from '@inzumer/ui-library';

   <Button variant="primary">Click me</Button>;
   ```

For the full walkthrough (Next.js example, package-manager specifics, testing an unpublished version
locally), see [Consuming The Library](/docs/documentation-consuming-the-library--docs).
